# Permutation Test for Directional Transition Asymmetry

Tests whether `label1` -\> `label2` transitions are more frequent than
`label2` -\> `label1` by comparing the observed directional asymmetry
score (n1 - n2) against a null distribution generated by randomly
shuffling event labels within each session many times. This controls for
both the base rates of each event type and the temporal structure of the
recording.

## Usage

``` r
permutation_transition_test(
  data,
  label1,
  label2,
  window_sec = 120,
  n_perm = 1000L,
  label_col = "vocalization_label",
  start_col = "session_relative_start",
  end_col = "session_relative_end",
  session_col = "session_label",
  require_adjacent = TRUE,
  seed = 42L,
  plot = TRUE
)
```

## Arguments

- data:

  A data frame of vocalization events (e.g.,
  `lys$vocalization_session_map`).

- label1:

  Character. First label (the hypothesised trigger).

- label2:

  Character. Second label (the hypothesised response).

- window_sec:

  Numeric. Matching window passed to
  [`compute_onset_latency()`](https://lxiao06.github.io/LYS/reference/compute_onset_latency.md).
  Default `120`.

- n_perm:

  Integer. Number of permutation iterations. Default `1000`.

- label_col:

  Character. Column holding the event label. Default
  `"vocalization_label"`.

- start_col:

  Character. Column holding event start time. Default
  `"session_relative_start"`.

- end_col:

  Character. Column holding event end time. Default
  `"session_relative_end"`.

- session_col:

  Character. Grouping column for sessions. Default `"session_label"`.

- require_adjacent:

  Logical. Passed to
  [`compute_onset_latency()`](https://lxiao06.github.io/LYS/reference/compute_onset_latency.md).
  Default `TRUE`.

- seed:

  Integer or `NULL`. Random seed for reproducibility. Default `42`.

- plot:

  Logical. If `TRUE` (default), draw a histogram of the null
  distribution with the observed statistic marked.

## Value

Invisibly, a list with:

- `observed`:

  Observed asymmetry score (n1 - n2).

- `null_distribution`:

  Numeric vector of permuted scores.

- `p_value`:

  One-sided p-value: proportion of permuted scores \\\geq\\ observed.

## Examples

``` r
if (FALSE) { # \dontrun{
res <- permutation_transition_test(
  data       = lys$vocalization_session_map,
  label1     = "BeggingCall",
  label2     = "SongBout",

```
